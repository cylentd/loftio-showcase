# Interface font

The showcase serves Nunito locally for its controls. The room artwork and exported postcard captions retain their separate treatments. No Google Fonts request is made by the running demo.

The Latin variable WOFF2 is unmodified and covers the interface's 400–600 weight range. The redistribution license is in OFL.txt.

Source verified 2026-11-04:
- Font: https://fonts.gstatic.com/s/nunito/v32/XRXV3I6Li01BKofINeaB.woff2
- License: https://raw.githubusercontent.com/google/fonts/main/ofl/nunito/OFL.txt
- Delivery metadata: Google Fonts CSS2, Nunito weights 400, 500 and 600.
