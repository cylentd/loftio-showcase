# Loftio · The Grove

A cozy treehouse loft where little residents wander, nap and keep you company.

**Live:** https://loftio.cylentlabs.com

- Drag a resident to a bed, a chair or the loft upstairs.
- Open Settings for rain, lamplight, lighting cycles and music.
- Make a postcard of the moment.

Built with [PixiJS](https://pixijs.com) and [Vite](https://vite.dev).

```
npm install
npm run build
npm test
```

This repo is exported from Loftio's private repo by `scripts/export_showcase.py`. Changes made here are overwritten by the next export.
